# Changelog

## 0.2.0

### Added

- Compare mode. Pick another Xcode's index from the toolbar and see what each framework added, removed, and changed, down to one symbol.
- A `diff` command in the CLI, with the same comparison as text or JSON.
- Compare With in a symbol's right click menu, which limits the comparison to that symbol and its members.

### Changed

- Updated every dependency to its newest version.

## 0.1.0

### Added

- The first release. Browse new SDK APIs by OS release, search the whole index, export a framework's new APIs as Markdown, summarize them on device, and use the bundled command line tool.
